# NASA FIRMS Dataset

This directory contains the datasets used for the NASA FIRMS Active Fire
Data Analysis project.

## Dataset Files

The analysis uses three NASA FIRMS active-fire datasets:

| File | Data Source |
|---|---|
| `small_dataset1.csv` | VIIRS J1 |
| `small_dataset2.csv` | MODIS |
| `small_dataset3.csv` | VIIRS SNPP |

## Dataset Description

The datasets contain satellite-based active fire detections and include
information such as:

- Latitude and longitude
- Brightness temperature
- Scan and track
- Acquisition date and time
- Satellite
- Instrument
- Confidence
- Fire Radiative Power (FRP)
- Day/night detection
